# Cisco manual TextFSM pack

NTC references are listed for each record set in `manifest.json`.
Referenced templates were adapted locally from ntc-templates 9.1.0:
Value names follow the selected NetOps CheckItem, samples determine supported
layouts, and absent source values remain absent. There is no runtime NTC fallback.
