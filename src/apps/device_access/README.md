# SSH 终端 App

平台公共的 SSH 终端，用法参照 SecureCRT。入口 `/apps/device-access`。

- 会话：名称、地址、端口、用户名、密码（加密保存，需要 `DEVICE_ACCESS_CREDENTIAL_KEY`）。会话不填用户名密码时使用默认用户名密码。会话和默认用户名密码按平台账号各自保存。
- 双击会话打开终端，多个终端以标签页并排。登录失败时弹窗输入用户名密码，可勾选“保存到会话”，登录成功后才保存。
- 主机密钥：首次连接显示指纹，确认后保存；密钥变化时警告，确认后替换。
- 终端票据单次有效、30 秒过期，在首帧传递，不放入 URL。

`device_access__collect` 让知识问答对人工选定的已保存会话执行固定诊断命令集；不接受密码或任意命令，失败后不自动重试。
