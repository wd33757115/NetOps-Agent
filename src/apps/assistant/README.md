按平台已有 install / migrate / enable / grant 流程交付，应用内不另设操作角色。
有 assistant 使用权的用户共用资料库；个人会话只允许其所有者访问。
当前开发环境已按该流程安装、迁移并启用；普通账号仍需管理员授予 assistant 使用权。

- `../materials/backend/`：资料导入与发布归属 Materials；Assistant 只读取已发布资料。
- `backend/history.py`：复用平台会话和消息表；旧聊天入口现在使用同一 App 权限与所有者边界。
- `backend/turns.py`：请求去重、单会话活动轮次、持久状态、取消、超时恢复及停用排空。
- `backend/api.py`：自动注册共用问答 API；历史引用只能打开本人会话实际保存的来源修订。
- `frontend/`：只保留旧页面地址到 `/chat` 的兼容跳转。
- `backend/workspace.py`：将修订快照在本地呈现为文件，映射实际读取行到原文引用。
- `migrations/`：资料、修订、问答轮次三张包内表；不新增任务执行器，固定业务仍使用各 App 的 Python/Celery。

当前问答只使用 `src/platform/agent_runtime/dsh.py`，由官方 SDK 管理 Agent 循环。
使用官方 glob/grep/read 和 MCP 客户端；没有固定检索顺序、LangGraph 或手写循环回退。
每轮总时限 90 秒、最多 12 次工具和 8 轮模型调用，单个 Gateway 进程最多同时启动两轮 SDK。
SDK 使用按用户与会话隔离的持久 home 和最小环境，退出撤销凭证并回收进程；
每轮在互斥锁下重建当前授权资料目录，原生会话及事件日志保留供恢复和追踪。
禁止任意路径、写入和 shell；MCP 只提供当前获授权的只读业务工具。
文件引用只接受本轮 read 的完整行，支持单行或行区间；旧修订仍可回查。
原知识库、旧知识节点桥接和 `KNOWLEDGE_TOOL_QA_ENABLED` 已移除；文件读取必须显式指定资料工作区。
0.3.0：两个入口共用执行过程面板，显示准备/分析/综合阶段、工具调用、章节标题、耗时及停止状态。
只保存执行摘要，不保存模型内部推理、原始工具参数或结果正文。每轮最多 30 项调用记录。
应用端只在问答运行期间轮询；聊天主入口通过 SSE 实时接收 progress 快照。
过程存入现有 turns 表的 nullable JSON 列（assistant_0002），并关联已保存的回答；刷新与切换会话可恢复。
完成后折叠展示，失败/中断保留提示；不自动重复提交。最终答案仍在引用校验后整段显示，未实现逐 token 输出。
旧 WebSocket 聊天已关闭，统一使用经过 BFF 认证的 SSE。

用户提供的华为云 Stack Word 样本保留在 `.runtime/assistant-eval/`，没有加入共享知识库。
用户已允许少量片段问答验证，仍禁止将整份原文或完整提取文本送入模型。
早期验证只使用一个 320 字符片段；后续评测使用 5 个选定片段（含标题/元数据共 2028 字符）。
DOCX 提取缺失图片、自动编号等信息，不能视为完整原文。

Agent 仅暴露清单中 `evidence=True` 的只读诊断工具。当前通过 inspection App 的
`search_devices/list_runs/list_events/list_snapshots/read_snapshot` 查询资产、各阶段质量、事件和原始证据。
查询结果分页、字段白名单；原文先脱敏再分页。命令、原文中的提示指令不能改变工具权限。
每次调用、最终发布引用、再次打开引用都检查源 App 使用权。历史列表不携带业务原文，详情经引用接口读取。
业务引用保存当次有界快照和摘要，记录 retrieved_at，并保留 observed_at 等原业务时间。
这是一套已有记录的诊断入口，不会发起设备采集、变更或规则发布。

每轮 progress 保存模型轮数、工具次数、输入字符累计、耗时与提供方实际返回的 token 用量；
未返回用量时为 null，不估算成 0。日志仅记录运行编号、终态、错误类别及统计，不记录密钥、完整提示或推理文本。
生产请求的 SDK 等待时限与外层90秒截止时间对齐；引用校验失败不发布未验证的答案，并显示具体失败类别。
