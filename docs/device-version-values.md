## 记录与校验

保留大写字段，不增加大小写别名映射。设备身份由采集上下文提供，SLOT 为记录主键；多台设备分别解析，不共用 Filldown 上下文。两组子槽位列表长度必须相同，编号不可重复、元素不可空，均无明细时保存空列表。TextFSM 使用 Value List，在同一 SLOT 行保留明细，不把一个父槽位展开成多条主记录。

只有原文明确适用于当前板卡，才可继承整机厂商、软件版本和镜像信息；板卡局部值覆盖公共值。运行时长优先取板卡自身，不能复制其他槽位时长。继承发生在基于 CLI 结构制作的 Parser 中；标准数据阶段只按同名接入，不执行猜测或字段改名。

必填项为空或显式不可用时记录为数据不完整；沿用现有质量状态：存在合格记录为 partial，全部不合格为 unavailable，并保留错误与原始证据。可选缺失不能补零或补正常。字段名存在与实际取到值分别校验。

UPTIME 保留文本证据，排除正常增长引起的字段变化事件；检测重启仍需后续连续采集证据与专项规则。本次不宣称实现重启识别，也不从镜像文件名推断软件版本。
