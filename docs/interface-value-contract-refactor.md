# 检查项同名 Value 与接口合并改造

## 决策与边界

检查项拥有标准字段和语义；新契约 `value_contract: same-name/v1` 强制 TextFSM 使用相同字段名。
没有 A→B 改名、枚举转换或单位换算。运行时现有版本化适配容器只保存同名字段引用和解析器绑定，
不调用 AI 生成映射。已按用户要求硬删除被合并检查项的历史资产，不提供旧接口链路回放。

`change_events: true` 为每个检查字段生成变化策略和信息事件，关闭则不生成。
对象标识用于匹配记录，不按普通指标比较。首次采集不冒充变化；缺失值不补零。
变化事件使用 `event_class=change`、`severity=info`、`evaluation_scope=change`，不纳入故障统计。
已有 CPU、内存和光功率健康策略不变。

## 接口合并

合并 `interface.oper_status` 与 `interface.statistics` 为
`interface.runtime_statistics`（接口状态运行信息和统计信息）。
人工要求的命令为 `display interface`。当前验证范围为 H3C S6850-56HF 与附件 Huawei X2E 样例，
不据此声称已覆盖其他型号或所有 VRP/Comware 输出变体。

1 个标识 `interface`，23 个检查字段：物理/协议状态、描述、MAC、带宽、速度、双工、链路类型、
PVID、三层 MTU、二层最大帧长、收发报文/字节/错误数、接收 CRC、最近物理 Up/Down 时间、协商、
介质模式和环回模式。字段定义集中在 `src/core/check_items/interface_values.py`。
未将设备当前时间纳入检查，避免必然变化的采集时钟淹没有意义的事件。

语义依据：用户提供的华为 X2E 命令说明、本地 NTC `hp_comware_display_interface` 与
`huawei_vrp_display_interface` 模板、用户的 H3C 两期原文。
NTC 用于参考记录边界与语法，没有直接复制其完整模板。
华为附件排版丢失换行；测试夹具按长空白恢复换行，未改动字段值。

## 生成、验证与迁移

- AI 解析方案上下文携带检查项完整契约；严格模式禁止额外 Value 和名称别名。
- 标准数据校验固定为同名引用；手工或 AI 提交改名/转换均被后端拒绝。
- 变化事件开关是程序强制约束，不允许模型跳过某个字段或凭空增加故障阈值。
- 模板按接口边界结束记录，避免旧模板等待输出错误行导致漏接口、跨接口串值。
- 收发总计与 PFC/Pause 子统计隔离；缺少发送错误总数保持缺失；MTU 与最大帧长分开。
- 生产解析器需要显式主键/必填字段元数据，不能只验证 TextFSM 正则本身。
- 默认目录统一为 `catalog.yaml`，标准语义统一为 `canonical_observations.yaml`。
  旧目录文件、旧接口语义、固定报表投影、Up/Down 初始化规则及启发式生成分支已删除。
- 已完成的旧接口迁移脚本、旧 A→B 手工验收脚本和过期默认候选已清理。
  其余当前检查项仍在调用的配置逻辑继续承担当前功能，不属于废弃历史代码。
