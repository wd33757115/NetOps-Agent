# 平台模块清理

页面入口、操作步骤和 App 启停命令见[应用管理与巡检预检操作](app-operations-guide.md)。

设备管理 1.0.3、网络巡检 1.2.11 删除旧“平台模块”页面、静态阶段列表、健康统计接口以及模块级维护开关。

应用是否可用由已有 App 生命周期和应用授权管理。正式巡检仍执行运行环境就绪、设备连接、命令与规则覆盖检查；解析、标准化、变化检测、事件及报告实现继续保留。

迁移 `0104_retire_module_controls` 删除 `netops_agent_module_controls`，不改动巡检数据和业务规则表。旧迁移保留，以支持从旧数据库顺序升级。迁移不使用 CASCADE；回退需恢复升级前数据库备份及匹配代码。

旧 `/agent-modules/health` 与 `/agent-modules/{module_id}/control` 接口退出服务，旧 `?tab=modules` 链接回到设备资产。巡检预览不再返回旧模块阻断字段。
