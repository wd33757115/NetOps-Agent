# 网络巡检 UI 1.2.0 验收

## 改动

- 独立宽版应用工作区，与防火墙策略、资料管理使用一致的浅灰背景、白色主区、蓝色操作与左侧导航。
- 五个业务入口：全部任务、在线巡检、离线巡检、风险与整改、质量反馈。保留 URL 深链接及原有证据、报告、整改功能。
- 任务中心提供最近任务统计、关键词搜索、来源筛选、任务摘要、结果与待办跳转。统计仅针对已加载列表（在线、离线各最近 20 项），不表达全量网络健康状态。
- 提供空数据、无匹配、加载中、部分来源失败及重试状态。宽屏显示摘要侧栏，窄屏改为纵向列表。
- 删除 JSX 中残留的字面 null 文本；任务列表不再强制 800px 宽度。复杂结果表仍在表内滚动，并可通过键盘聚焦。
- 显式“全部任务”导航优先于历史批次参数，防止从详情返回任务中心时被旧批次参数强制切回在线页。打开批次时明确激活在线页。
- 设备管理与命令集入口合并为“设备与命令集”，继续前往既有设备页面。未更改业务执行、App 权限、API、数据库或队列。

## 验证

- 前端 52 个测试文件、237 项测试全部通过（新增 7 项覆盖导航、选择摘要、深链接、搜索/来源筛选、空列表和失败重试）。
- 修改的 TypeScript/TSX 文件 ESLint 通过；生产构建通过。
- 实际 API 与已有历史任务：五个导航页面、在线/离线创建入口、历史离线巡检结果查看均通过。未提交新巡检、未连接设备执行采集。
- 浏览器检查 2538、1440、390 像素宽度；任务页和五个巡检页面手机宽度无整页横向溢出。
- 浏览器内合成任务验证不同来源、完成/运行/失败/阻塞状态、摘要选择和响应式列表；合成数据未写入数据库。
- Axe 对真实任务桌面页和合成任务手机页检测：无 serious/critical 问题。未宣称巡检内所有历史详情组件已完成完整无障碍审计。
- 验证产物：`.runtime/inspection-ui/`；原始文件备份及 SHA256 清单：`before/`、`baseline.json`。
