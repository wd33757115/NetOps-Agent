# 检查项字段语义编辑

核对日期：2026-09-24。已实施并在本地启用。

## 实施计划

1. 在检查项字段中直接编辑含义、语义类型、评估用途、状态分类；已有观测目录只作预填模板。新增语义不再要求先修改全局 YAML。
2. 数值字段复用现有阈值引用与比较约束，提供字段选择和比较方式编辑，不新增执行器或规则体系。
3. 后端验证当前检查项的局部定义并生成语义快照与摘要；保存仍走检查项草稿、影响预览和发布流程。局部修改不改变其他检查项或已发布规则。
4. 编辑已有检查项优先读取其快照，保留未编辑的高级属性。规则生成、运行装配使用同一快照。
5. 验证新增、编辑、重新打开、非法状态分类、数值字段引用与规则生成；构建前端并按现有能力包流程更新本地服务。

## 数据约定

每个 observations 字段可携带 semantic_definition 局部定义。服务端验证后写入 rule_semantics_snapshot，并以实际内容计算摘要。客户端提供的摘要不作为新草稿的可信依据。

全局 canonical_observations.yaml 继续提供模板；已有检查项不强制迁移，不自动重新发布检查项、规则或运行包。

## 使用方式

在规则治理的检查项目录中新增或编辑检查项。每个标准字段下的“编辑语义与规则用途”支持：

- 输入新观测标识，或从已有目录选择模板；含义说明保存到当前检查项。
- 选择状态、文本、数值测量、累计计数、阈值参考等类型，以及健康判断、变化检测、仅展示等用途。
- 为状态填写允许取值和正常、异常、未知、过渡分类；正常和异常分类用于健康规则生成，分类不得交叉。
- 数值字段可引用同一检查项的上限、下限、严重阈值字段，单位必须一致；缺少阈值时不能通过隐含固定值判定健康。
- 设置精确比较、状态转换、数值变化、计数增量等执行器支持的比较方式。不修改的基线、列表、维度和高级约束保留。

关闭“全部字段变化事件”时仍可逐字段选择变化检测。健康用途还受检查项整体评估模式约束：仅展示模式不执行健康判断。
页面下方“按当前已发布语义预览规则”继续针对已发布版本；草稿修改需先经过影响预览和发布，才用于后续规则制作与运行包装配。

全局模板目录暂不可用时，已有快照和手工新增字段仍可编辑。新增字段必须填写含义说明；修改不会写回全局模板目录。
