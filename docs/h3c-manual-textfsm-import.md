## 字段与语义

已有同义检查项继续使用 same-name/v1 字段，接口状态运行信息和统计信息的定义未改动。
NTC 参考文件名、许可证和模板清单位于 `scripts/check_items/h3c_manual_templates/`。
以下 12 个新检查项补足现有定义无法准确表达的原文粒度，均只提供证据：

| 检查项 | 原文含义 |
| --- | --- |
| device.subslot_inventory | 槽位、子槽位、组件及版本说明；同 Subslot 0 多个组件分别保存 |
| device.manufacture_inventory | 原文章节范围、部件类型与编号、型号、序列号、制造日期、厂商、订货号 |
| environment.fan_speed_level | 风扇档位；不冒充 RPM 转速 |
| interface.link_brief | 路由／桥接接口简表中的状态、速率、协议、PVID、描述 |
| interface.ip_brief | IP、明确给出的前缀长度、VPN 和协议状态 |
| network.arp_entries | IP、VLAN/VSI、接口、MAC、老化原值与类型；不把 VLAN 当成 VRF |
| network.mac_forwarding | VLAN、MAC、端口逐行记录；保留一个 MAC 在多个端口出现的情况 |
| redundancy.irf_members | IRF 成员、角色、优先级、CPU MAC；角色不等同于健康状态 |
| configuration.startup_files | 当前、下次主用与备用启动配置文件路径；不是配置文件正文 |
| redundancy.mlag_system | M-LAG 本端／对端系统标识、MAC、角色、优先级与独立模式 |
| redundancy.mlag_timers | 定时器状态、秒数及剩余时间；缺失值不补零 |
| operations.syslog_records | 日志时间、主机、模块、级别、助记符及正文，支持本批跨行正文 |

制造信息中的 SCOPE 表示原文最近的 Slot/Chassis 标题上下文，不推断部件实际物理归属。
NTC 仅作为字段和格式参考，运行时没有恢复“优先尝试 NTC”或 Value 映射机制。

光模块分别处理缺失／不支持 DOM、单通道和多通道格式；多通道读数与公共门限一起保留，
并区分告警门限和预警门限。运行时已修正一处误判：带完整时间戳的设备历史日志提到
“命令不支持”时，不再当成当前采集失败；独立 CLI 错误、分页、截断仍正常识别。
