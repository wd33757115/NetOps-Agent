# 工作台使用说明

核对日期：2026-09-23。入口 `/workbench`，桌面内容由当前用户已获使用权且已启用的 App 决定。

## 应用与个人布局

知识问答统一从聊天页面使用，工作台桌面、文件夹和 Dock 不再显示独立的“知识问答”图标。点击 NetOps 菜单中的“新建聊天”或历史会话即可进入；Assistant 服务与使用权限继续保留。

桌面双击打开应用；手机轻点打开。拖动图标可放到整个可见桌面的网格位置，包括宽屏右侧。网格随可用宽度展开；窗口缩窄时仅调整显示，不覆盖原来的保存坐标，恢复宽屏后恢复原位置。

支持新建/重命名/解散一层文件夹、移入/移出应用，以及 Dock 固定和排序。图标操作菜单提供键盘/触摸替代操作。桌面不改变 App 实际权限，也不启动巡检任务。

## 更换壁纸

在桌面空白处右键选择“更换壁纸”。选择内置背景，或上传自己的 JPG、PNG、WebP 图片；预览后点击“应用壁纸”。“取消”放弃本次选择，“恢复默认壁纸”选回远山背景后仍需确认应用。

上传文件最大 10 MB；浏览器将图片缩放为最长边不超过 2560 像素的 JPEG，保存内容不超过 512 KiB 的编码长度。不能有效压缩或无法读取时会提示重选。背景居中铺满桌面，图片边缘可能裁切，浅色图片叠加轻微遮罩以保持图标文字可读。

壁纸与布局按登录用户保存到服务器，刷新或同账号其他浏览器重新加载可恢复。退出/切换账号会重置当前缓存。不会修改其他用户的桌面；不支持外部图片 URL 或 SVG。

## NetOps 菜单与历史会话

点击左上角 NetOps 打开导航侧栏，直接加载当前账号的历史会话，无需先进入聊天页面。可搜索、打开已有会话或新建聊天。加载失败显示重试入口；打开会话后侧栏关闭并进入聊天页。会话内容及权限仍由服务端验证。

## 保存、冲突与恢复

布局和壁纸共用 `GET/PUT /api/auth/me/desktop-layout/`；用户由 JWT 确定。修改在短暂防抖后保存，PUT 携带读取的 revision；并发修改返回 409。界面保留本地草稿，由用户决定是否加载服务器最新设置。

保存失败可以重试，读取失败不会用默认布局覆盖服务器。旧客户端只修改图标时，后端保留已保存壁纸。用户设置存于 PostgreSQL 的 Django schema，不需要为本次功能新增数据库迁移。

## 巡检应用

网络巡检入口为 `/apps/inspection`。左侧进入全部任务、在线巡检、离线巡检、风险与整改、质量反馈；任务页提供搜索、来源筛选、摘要与结果跳转。统计仅覆盖当前列表（在线/离线各最近 20 项），不表示全网健康状态。宽屏使用列表与摘要双栏，手机使用纵向任务列表。

新建巡检选择在线采集或离线文件，再执行原有预检/确认流程。执行完成后检查覆盖范围、业务结论和原始证据，再交付报告。详见[巡检操作](patrol-workflow-refactor-guide-2026-09-05.md)。

## 设备管理应用

入口 `/apps/device-management`，在工作台独立显示。沿用防火墙策略的全宽工作区、左侧导航与蓝色主操作，支持资产列表、导入预览、动态分组、设备详情、编辑、连接维护、命令集绑定及平台模块健康。大屏展开清单；手机导航与宽表格分别横向滚动。

管理员在用户或用户组的 App 授权中单独控制“设备管理”。首次升级自动继承原规则治理的直接和用户组授权；此后两者独立，不会反复同步。仅有巡检权限的用户仍可选择设备并巡检，维护入口仅向拥有设备管理权限的用户显示。

设备数据、历史证据和凭据引用沿用原有存储。旧设备管理地址自动跳转到新应用，规则治理不再包含设备管理子页。

## 规则治理与规则生成

当前规则治理 1.3.0 新增“规则包导入导出”。检查项目录与已发布资产支持多选导出，自动携带必要依赖；导入先预检差异，原子写入待验证版本，不覆盖当前生效规则。操作与格式见[规则包使用说明](rule-package-transfer-guide.md)。

2026-09-23：规则治理 1.1.0 已在本地正式环境启用。经用户明确确认，升级排空取消了 76 个处于 collecting 状态的 Parser 任务，任务记录保留；此次未发起新的规则生成或发布。

入口 `/apps/rule-governance`。应用采用与防火墙策略、资料管理一致的独立工作区：左侧业务导航，右侧列表、表单和详情。宽屏展开可用空间；手机导航可横向滑动，制作任务按纵向列表展示，直接操作下一步，其他宽表格在各自区域滚动。

| 页面 | 主要操作 |
| --- | --- |
| 制作任务 | 搜索检查项、筛选制作状态，展开命令明细，继续 Parser、规则验证或发布 |
| 样本导入 | 导入单周期或双周期 CLI 输出，进入样本任务详情查看文件、证据和制作进度 |
| 检查项目录 | 编辑检查标准和命令适配器，查看变更与审批 |
| 已发布资产 | 按资产类型查看生效版本、验证依据与详情 |
| 覆盖与回填 | 查看覆盖健康、历史回填、渐进发布和治理缺口 |
| 审计记录 | 检索操作记录并回查发布依据 |

导入、检查项编辑、工程师复核、命令生产和资产详情沿用原有业务操作，统一抽屉标题、表单、证据区与操作栏。样本任务详情保留独立地址 `/apps/rule-governance/source-jobs/:jobId`；来自巡检的补齐链接保留返回路径。

点击查看详情不会自动发起生成、审批或发布。加载失败显示原因并提供重试，不用空列表替代失败状态；“变更与审批”仍会校验历史候选资产的完整性。UI 改造不修改现有业务数据，也不改变 App 使用权限或固定执行流程。

## 系统管理

管理员可通过工作台顶部“系统管理”或账号菜单进入用户、用户组和应用授权页面。普通账号不显示入口且接口拒绝访问。详见[系统管理操作说明](system-management-guide.md)。
