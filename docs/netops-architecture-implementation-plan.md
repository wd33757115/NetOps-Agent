# NetOps 实施状态与后续验收

核对日期：2026-09-22。本文是当前实施状态入口，替代旧 v2 计划与重复批次进度汇总。

## 已落地

- P1–P2：应用注册内核、公文试点、用户/组 App 授权、包版本/摘要、迁移、部署校验与停用排空。
- P3：防火墙策略作为完整业务包交付。
- P4：规则治理、生成与发布流程归包，使用固定业务任务。
- P5：在线/离线巡检、历史比较、证据重放、报告及恢复/取消归包；新执行不依赖 Workflow。
- P6 已交付部分：DSH 替换问答执行器，原生文件检索与 MCP 业务证据查询、引用核对、执行过程、历史恢复及明确失败提示。原知识库 API/索引/依赖入口退役。
- 后续产品完善：资料整份发布及修订/生命周期治理、巡检宽版 UI、工作台个人壁纸、全宽图标拖放和菜单历史会话。

本地版本基线：Assistant 0.6.1、Materials 1.2.0、Inspection 1.2.0、Firewall Policy 1.0.1、Official Documents 1.1.0、Rule Governance 1.0.0。版本号不作为其他环境启用成功的证据。

## P6 待验收

1. 使用更多独立真实资料与未见题集，完成网络专家对事实、配置完整性和引用的审核。
2. 验证 Word 图片、拓扑、复杂表格等提取限制下的业务可用性；现有可提取正文整份发布不代表视觉内容无损提取。
3. 在目标服务器执行持续负载、取消/超时、进程回收、权限变化及恢复验证。

P6 整体尚未宣布完成。详见[P6 验收状态](netops-capability-packages-p6.md)。不为后续验收引入第二套 Agent、向量检索或业务 Workflow 引擎。
