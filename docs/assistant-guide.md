# 资料检索与知识问答

核对日期：2026-09-22。问答统一从 `/chat` 使用；原 `/apps/assistant` 页面已删除，旧地址自动跳转到聊天页。要求 assistant App 使用权；业务工具还需对应业务 App 使用权。共用问答后端和已有会话保持不变。

## 检索方式

资料从[资料管理](materials-guide.md)发布。DSH 使用原生 glob、grep、read 查目录、搜索关键词、定位章节并按行分页阅读；模型根据实际结果决定下一次调用。平台限制资料范围与预算，保留可追溯引用。没有 LangGraph、Supervisor 图或旧 RAG 知识库回退。

导入/发布本地资料不会调用模型。问答只读取相关片段，文件大并不意味着整份进入模型上下文。图片、复杂表格或自动编号的提取限制必须在导入预览中核对，不能从缺失文字推断图像内容。

## 执行过程与答案

发送后页面展示准备、检索、阅读、业务查询、综合与最终状态。展开工具步骤可查看真实工具名、脱敏参数、相对路径、读取范围/结果计数及耗时。在 `grep`、`glob`、`read` 步骤下点击“查看执行结果”，可展开匹配内容、文件路径、行号或阅读片段。每步预览最多 12,000 字符，截断会明确提示；结果按纯文本展示。历史会话可回看这些记录；它是执行记录，不是内部思维链。升级前未保存的结果正文无法补回，需要重新提问。

草稿由同一次 DSH run 内的引用工具核对，缺少阅读或引用不匹配时可反馈补读。发布前再次核对资料修订与源 App 权限，引用点击后可回查相应原文。资料不足、授权变化、预算耗尽、模型输出截断和引用失败应显示各自原因，不能当作设备正常或诊断完成。

完整配置回答基于已读原文。缺少设备型号、软件版本、地址或现场端口时，结果只能作为待替换参数的模板；不能把手册示例当成当前设备完整实测配置。

“证据不足”不等于“没有搜到”。先展开执行过程：`grep` 的匹配数说明搜索命中，`read` 的行数说明已读取正文。读过正文仍不足以支持结论时，页面会说明证据不足，不再提示章节未发布。简短产品描述也可检索和引用，但引用只证明来源写了什么，不证明产品宣称已被验证。

## 实现与验证

### 会话续接与服务器追踪

从 Assistant 0.7.0 起，同一用户、同一聊天、同一资料与工具范围持续使用同一个 DSH 原生会话。SDK 进程退出或服务重启后可恢复。资料修订、筛选条件、可用工具或本轮诊断连接变化时，切换隔离会话；新聊天也使用独立会话。每轮仍重新校验权限，引用仍要求本轮实际读取原文。

旧聊天首次接入时以现有最近聊天文本建立原生会话，之前的 SDK 工具上下文无法补回。后续只提交本轮问题，不重复拼接历史。当前固定 SDK 未启用上下文压缩；累计上下文达到平台容量上限时，会提示新建聊天，已有记录继续保留。

原生持久化与事件保存在项目 `.runtime/assistant-sessions/`，不随 Git 提交，不会作为额外的会话日志上传至模型提供方。普通聊天与安全预览继续保存在 NetOps 数据库。服务器目录结构：

```text
assistant-sessions/<用户与聊天组合哈希>/scopes/<资料与工具范围哈希>/
  sessions/…/session.v3.jsonl  # DSH 原生持久化，恢复会话使用
  runs/<运行编号哈希>.json    # 对应 NetOps run_id、conversation_id 与原生 session_id
  runs/<运行编号哈希>.jsonl   # 该轮 SDK session.event/session.status 通知
```

运维排查可用页面请求中的 `run_id` 在 `runs/*.json` 查到对应事件文件。原生日志可能包含实际资料片段、业务结果和消息，应仅允许服务账户及授权运维访问；不可放入静态文件目录或向普通用户下载。备份时同时备份数据库和该目录。文件可能超过 Windows 传统路径长度，维护工具需支持长路径。原生记录目前无自动过期清理；只在会话不再使用且符合保留要求时离线归档整个会话目录，不能删除正在使用的原生日志。

运行使用固定 `deepseek-harness-sdk==0.1.5rc1`。该版本 JSON-RPC 入口重启后直接创建同名会话，NetOps 小型兼容插件在原生日志存在时改用官方 `agents.resume`。执行循环、持久化格式及恢复仍由 DSH 管理。升级 SDK 时必须先执行跨进程恢复回归。参考 [官方 Python SDK 指南](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/python-sdk.md)与[官方恢复问题讨论](https://github.com/deepseek-ai/deepseek-harness/discussions/6295)。

当前实现见[Assistant 包](../src/apps/assistant/README.md)、[DSH 适配器](../src/platform/agent_runtime/dsh.py)和[助手验证脚本](../scripts/assistant/README.md)。SDK 是唯一执行循环，平台只适配会话、预算、权限、业务工具与证据。
