# GitHub 仓库内容范围

仓库只交付程序源代码、使用与维护手册、安装启动脚本及其必要依赖配置。

## 保留内容

- `src/`、`web/`：后端、前端、App 源码及运行必需的内置资源，包括 Word/Excel 模板。
- `migrations/`、`schemas/`、`config/`：数据库迁移、协议和程序配置定义。
- `requirements*.txt`、依赖锁文件、构建配置：用于从源码安装和复现环境。
- `scripts/`、`deployment/`：安装、启动、升级、备份恢复和维护工具。
- `docs/`、README：使用、部署、运维和开发参考手册。
- `tests/`、源码中的测试及视觉基准：验证代码及固定测试夹具。
- `.github/`、许可证、Git 配置：仓库检查和发布所需元数据。

## 仅保留在本机

运行日志、真实设备采集、数据库备份、业务上传资料、生成报告、临时截图、构建结果、依赖目录、个人配置与密钥不上传。内部方案、阶段验收记录和 AI 输出也不纳入 Git。

`.gitignore` 对仓库根目录使用允许列表，新目录默认不上传；内部过程文档使用单独排除规则。不要使用 `git add -f` 绕过规则。

检查暂存区范围：

```powershell
python scripts/check_repository_scope.py
git diff --cached --stat
```

GitHub CI 执行相同范围检查，并且不自动上传测试报告、截图等 Actions 附件。固定视觉基准是测试输入，不属于运行时截图。

已跟踪文件必须通过 `git rm --cached -- <文件>` 取消跟踪，仅添加 ignore 规则无效。取消跟踪不会删除本机文件；提交并推送后才会从远端当前版本移除。既有提交历史不会因此清除，需要清理历史时应另行安排，不能直接强制推送重写历史。
