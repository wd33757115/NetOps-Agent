# 资料管理

核对日期：2026-09-22。入口 `/apps/materials`，使用 materials App 权限；不增加资料内部角色权限。

## 导入与发布

选择 Word 文件，先本地解析并预览章节、表格及提取告警。核对后发布整个文件的可提取正文，问答可按需检索所有已发布章节，不要求人为逐章发布。上传与发布不调用模型；原始文件、内容修订和引用绑定保存。

“整份发布”不等于对 Word 所有视觉内容无损还原。图片、拓扑图、图中文字、自动编号及复杂单元格以实际告警和预览为准；不能把提取缺失当成原文没有。

## 维护

- 编辑产品、厂商、软件版本等元数据；保存新修订。
- 对比修订的章节变化与元数据差异，查看原文及原文件。
- 停用：不再参与新问答；恢复后重新可检索。
- 删除：从资料列表和新问答中移除，历史引用对应的修订及原文件仍可回查。当前不是物理擦除操作。
- 批量 Word 导入与内容去重按页面反馈处理，不以文件名相同推断内容相同。

资料管理提供治理入口，Assistant 消费已发布内容。详细实现及限制见[业务包](../src/apps/materials/README.md)，用户问答行为见[问答指南](assistant-guide.md)。
